# SnapCut macOS 原生版

这是 SnapCut 的 macOS 原生重写，不替换当前 Electron 版本。当前阶段已经可以验证低内存、低延迟的截图主链路、基础标注体验和区域录制：菜单栏常驻、全局快捷键、窗口自动吸附、屏幕选区、标注、复制 PNG、保存 PNG 和保存 MOV 录制文件。

## 要求

- Apple Silicon Mac
- macOS 13 或更高版本
- Swift 6 / Xcode Command Line Tools

## 构建和运行

\`\`\`bash
./build-app.sh
open build/SnapCut.app
\`\`\`

第一次截图时，macOS 会要求授予“屏幕录制”权限。权限路径是“系统设置 → 隐私与安全性 → 屏幕录制”。

默认截图快捷键是 \`Control + Command + A\`，默认录制快捷键是 \`Control + Command + R\`。截图框选后可以点击工具栏按钮，也可以使用 \`Enter\` / \`Command + C\` 复制，\`Command + S\` 保存，\`Esc\` 取消。

## 当前功能

- 点击窗口自动吸附，拖拽选区边缘时会贴近窗口和屏幕边缘。
- 截图和录制控制栏改为底部居中的原生毛玻璃浮层，按钮按工具、样式、历史和导出分组。
- 选区边框改为高对比外描边加功能色内描边，暗色和亮色桌面上都更容易看清。
- 支持矩形、椭圆、箭头、画笔、马赛克和文字。
- 选择标注工具后会保持当前工具，可连续绘制多个同类标注。
- 绘制矩形、椭圆和马赛克时按住 Shift 可以等比例生成正方形或正圆；缩放已有标注时按住 Shift 可以锁定比例。
- 每个工具会记住自己的颜色和粗细，颜色使用截图蒙层内置色盘，粗细使用无级滑杆并带实时预览。
- 点击截图控制栏空白处不会重置选区或退出截图。
- 已画完的标注可以重新点选、拖动、缩放、改颜色和改粗细。
- 文字点击后输入，点击空白处会保留文字；双击已有文字可以再次编辑。
- 支持撤销、重做、删除选中标注、复制和保存。
- 菜单栏或 \`Control + Command + R\` 提供开始录制，框选录制区域后开始无声屏幕录制；停止后自动保存到 \`~/Movies/SnapCut\`。
- 菜单栏提供偏好设置，可以选择是否显示菜单栏图标。
- 菜单栏提供检查更新入口；正式自动安装会在原生版签名和公证流程完成后接入。

## 当前边界

这一阶段的录制先支持无声区域录制，还没有加入系统声音、麦克风、录制倒计时和暂停/继续。正式签名、公证、DMG 安装包和 Sparkle 自动升级也还没有接入。现有 Electron 版保持不变。
